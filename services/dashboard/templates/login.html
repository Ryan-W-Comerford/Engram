Where do I find the token?
1
Open the .env file
On the machine running Engram, open the .env file next to docker-compose.yml and copy the value after AUTH_TOKEN=.
2
Paste it above
The same token authenticates the SDK (Engram(token="…")) and OTel exporters (Authorization=Bearer …).
If AUTH_TOKEN is left blank, Engram runs with no login at all — you would not be seeing this screen.
