SDK Quickstart

Instrument any Python app in under a minute

1 · Install
pip install -e ./sdk
2 · Instrument (FastAPI)
from engram_sdk import Engram

pulse = Engram(
    host="{{ ingestor_host }}",
    environment="production",
    service="my-api",
    # token="…" only if this instance sets AUTH_TOKEN
)
pulse.auto_instrument(app) # wraps FastAPI or Flask
3 · Manual capture (optional)
try:
    result = call_external_api()
except TimeoutError as e:
    pulse.capture_error(exception_type="TimeoutError", message=str(e))
