SDK Quickstart

Instrument any Python app in under a minute

1 · Install
pip install -e ./sdk
2 · Instrument (FastAPI)
from pulseai_sdk import Engram

pulse = Engram(
    api_key="pk_live_…", # use ENGRAM_API_KEY env var in prod
    host="{{ ingestor_host }}",
    environment="production",
    service="my-api",
)
pulse.auto_instrument(app) # wraps FastAPI or Flask
3 · Manual capture (optional)
try:
    result = call_external_api()
except TimeoutError as e:
    pulse.capture_error(exception_type="TimeoutError", message=str(e))
4 · Record a deployment from CI/CD
pulse.capture_deployment(commit_sha="a3f8c21", branch="main", pusher="ryan")
